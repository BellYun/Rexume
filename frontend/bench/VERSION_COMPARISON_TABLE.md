## 🔍 기술별 상세 설명

### 1. RAF 페인트 안정화 (Double RAF)
- **설명**: 렌더링 완료 후 `requestAnimationFrame`을 2번 호출하여 브라우저 페인트 타이밍과 동기화
- **효과**: 레이아웃 시프트 감소, 페인트 안정화
- **단점**: 추가 대기 시간 발생 (약 16-33ms)
- **적용 버전**: Opt1, Opt3, Lazy, Opt8, RAF

### 2. Callback Ref 패턴
- **설명**: `useCallback`으로 ref 함수를 메모이제이션하여 불필요한 재생성 방지
- **효과**: 리렌더링 최적화, ref 함수 재생성 방지
- **적용 버전**: Opt2, Opt3, Opt7, Opt8, Opt9, Opt10, RAF

### 3. RenderScheduler (K=4)
- **설명**: 동시 렌더링을 최대 4개로 제한하는 스케줄러
- **효과**: 메모리/CPU 사용량 제어, 과도한 동시 렌더링 방지
- **적용 버전**: Opt7, Opt8, Opt9, RAF

### 4. RAF 배칭
- **설명**: IntersectionObserver 콜백을 `requestAnimationFrame`으로 배칭하여 한 프레임에 묶어 처리
- **효과**: 레이아웃 재계산 감소, 프레임 효율성 향상
- **적용 버전**: Opt5, Opt7, Opt8, Opt9, Opt10, RAF

### 5. 우선순위 정렬
- **설명**: viewport 중심과의 거리를 계산하여 가까운 페이지를 우선 렌더링
- **효과**: 사용자 체감 성능 향상, 중요한 페이지 우선 렌더링
- **적용 버전**: Opt7, Opt8, Opt9, RAF

### 6. IntersectionObserver 프리워밍 (75vh)
- **설명**: `rootMargin`을 75vh로 설정하여 뷰포트 진입 전에 미리 렌더링 시작
- **효과**: 스크롤 시 즉시 표시, 프리로딩 효과
- **적용 버전**: Opt7, Opt8, Opt9, Opt10, RAF

### 7. Lazy getPage
- **설명**: 페이지 크기 계산을 위해 `getPage()`를 미리 호출하지 않고, 실제 렌더링 시점에만 호출
- **효과**: 초기 로딩 시간 단축, 불필요한 작업 제거
- **적용 버전**: Lazy, Opt10

## 📊 버전별 특징 요약

### 🥇 Opt10: Lazy + Pure RAF
- **핵심 기술**: Lazy getPage + RAF 배칭 + Callback Ref + IO 프리워밍
- **특징**: 스케줄러 없이 순수 RAF로만 처리, 가장 빠른 렌더링
- **성능**: 1,641ms (1위), TBT 221ms (3위)

### 🥈 Opt9: RAF 페인트 제거
- **핵심 기술**: RenderScheduler + RAF 배칭 + 우선순위 + Callback Ref (페인트 안정화 제거)
- **특징**: opt8에서 페인트 안정화만 제거하여 속도 향상
- **성능**: 1,905ms (2위), TBT 223ms (2위)

### 🥉 Lazy
- **핵심 기술**: Lazy getPage + RAF 페인트 안정화
- **특징**: 간단한 구조로 우수한 성능
- **성능**: 1,826ms (3위), TBT 213ms (1위)

### Opt3: Combined
- **핵심 기술**: RAF 페인트 안정화 + Callback Ref
- **특징**: PDF 컴포넌트 레벨 최적화만 적용
- **성능**: 2,007ms (4위), TBT 293ms (4위)

### Opt8: RAF 페인트 + 배칭
- **핵심 기술**: 모든 스케줄링 기술 + RAF 페인트 안정화
- **특징**: opt7 + 페인트 안정화
- **성능**: 2,137ms (5위), TBT 342ms (7위)

### Opt7: 전체 스케줄링
- **핵심 기술**: RenderScheduler + RAF 배칭 + 우선순위 + Callback Ref
- **특징**: 스케줄링 최적화의 집합체 (페인트 안정화 없음)
- **성능**: 2,354ms (9위), TBT 388ms (10위)

### Opt5: RAF 배칭
- **핵심 기술**: RAF 배칭만 단독 적용
- **특징**: 스케줄러 없이 배칭만 사용하여 성능 저하
- **성능**: 2,669ms (12위, 최악), TBT 681ms (12위, 최악)

## 💡 주요 인사이트

1. **Lazy getPage가 가장 효과적**: Opt10과 Lazy가 상위권을 차지
2. **RAF 페인트 안정화는 선택적**: Opt9가 Opt8보다 빠름 (페인트 안정화 제거)
3. **스케줄러 단독 사용은 비효율**: Opt5 (RAF 배칭만)가 최악의 성능
4. **복합 최적화의 시너지**: Opt7, Opt8, Opt9는 스케줄링 기술 조합
5. **Callback Ref는 필수**: 대부분의 최적화 버전에 포함
