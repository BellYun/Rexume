```

❌ 나머지 모든 최적화 제외
```

## 🔥 핵심 발견

### 1. 단순함이 최고
- **Lazy** (2개 기술): 렌더링 1위, TBT 1위
- **RAF** (7개 기술): 렌더링 3위, TBT 2위
- **결론**: 복잡도와 성능은 비례하지 않음

### 2. Lazy getPage가 핵심
- Lazy getPage 적용 버전: 1위, 2위
- 미적용 버전: 3~7위
- **결론**: 필수 기술

### 3. RAF 배칭 재검토 필요
- Opt10 (RAF 배칭 O): Long Tasks 5.0개 (최악)
- Lazy (RAF 배칭 X): Long Tasks 2.0개 (2위)
- **결론**: Lazy getPage와 조합 시 오히려 부담

### 4. 과도한 최적화는 아니었음 (재평가)
- 이전 측정: RAF가 최하위
- 이번 측정: RAF가 3위, TBT 2위
- **결론**: 측정 환경에 따라 결과 다름

### 5. Simple보다 Basic이 빠름
- Simple이 IntersectionObserver만 추가했는데 오히려 느림
- **결론**: 단순 IO만으로는 부족
